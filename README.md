## Структура проекта

- **3 страницы с семантической разметкой:**
  - `index.html` - главная страница со списком статей блога
  - `article.html` - страница отдельной статьи
  - `chat.html` - страница онлайн чата

## Особенности

### Семантическая разметка

- Использование HTML5 семантических элементов (`header`, `nav`, `main`, `article`, `section`, `aside`, `footer`)
- Правильная структура заголовков (h1-h6)
- ARIA-атрибуты для улучшения доступности
- Семантически корректные формы с лейблами и описаниями

### Стилизация

- Современный адаптивный дизайн
- CSS Grid и Flexbox для макетов
- Плавные анимации и переходы
- Мобильная адаптивность

### Линтеры и качество кода

- ESLint для проверки JavaScript и HTML
- Prettier для форматирования кода
- HTMLHint для валидации HTML
- GitHub Actions для автоматической проверки

## Особенности реализации

### Главная страница (`index.html`)

- Список статей в виде карточек
- Метаинформация (дата, категория)
- Превью статей с ссылками "Читать далее"

### Страница статьи (`article.html`)

- Полноценная статья о семантической верстке
- Структурированный контент с заголовками
- Навигация обратно к списку статей

### Страница чата (`chat.html`)

- Интерфейс чата с историей сообщений
- Форма для ввода имени и отправки сообщений
- Правила чата в боковой панели
- ARIA-атрибуты для доступности
